# 사진 경로 테스트

사진 설명: 루트 `.env`의 `GEMINI_API_KEY`를 설정하고 서버를 재시작하면 페이지에서 JPG를 순서대로 Gemini에 전송하고 한국어 설명을 사진 카드 제목으로 자동 표시합니다. 지도 로딩과 독립적으로 처리합니다. `GEMINI_MODEL`로 모델을 지정할 수 있으며 기본값은 `gemini-2.5-flash-lite`입니다. 14MB 이하 사진을 지원하고, 생성한 제목은 루트 .cache/photo-titles/에 사진 내용의 SHA-256 해시별 JSON 파일로 영구 저장합니다. 새로고침이나 서버 재시작 시 저장된 제목을 API 요청 없이 재사용합니다. 파일 이름이 바뀌어도 내용이 같으면 재사용하고, 사진 내용이 바뀌면 새로 생성합니다. 저장 파일은 Git에서 제외합니다. 생성된 설명은 AI 설명으로 표시되며 일시적 오류는 최대 3회 시도하며, 실패 시 기본 제목과 오류 안내를 표시합니다. 페이지를 새로고침하면 다시 요청합니다.

도로 경로를 표시하려면 루트 `.env`에 `KAKAO_REST_API_KEY`도 설정하고 서버를 재시작합니다. 이 키는 JavaScript 키와 별도로 카카오디벨로퍼스에서 발급받은 REST API 키입니다. 서버에서 카카오모빌리티 다중 경유지 길찾기를 호출하며 브라우저에는 REST 키를 전달하지 않습니다.

촬영 순서대로 자동차 추천 경로를 조회합니다. 경유지는 요청당 최대 30개로 나누고, 성공한 결과는 5분 동안 메모리에 보관합니다. API는 요청 경로 총 거리 1,500km 미만을 요구합니다. 연결 불가능한 위치나 API 오류가 있으면 사진 마커는 유지하고 오류를 표시합니다. 표시되는 거리와 시간은 현재 추천 경로 기준이며 실제 여행 기록이 아닙니다.

Node.js 22 이상에서 프로젝트 루트의 `.env`에 `KAKAO_MAP_JAVASCRIPT_KEY`를 설정하고, 카카오 JavaScript SDK 도메인에 `http://localhost:5173`을 등록합니다.

```sh
cd test
npm install
npm start
```

브라우저에서 http://localhost:5173 을 엽니다. 저장소 루트에서도 `node test/server.mjs`로 실행할 수 있습니다.

- 화면 상단에서 아이폰(`photo_sumin/`) 또는 갤럭시(`photo_seongmin/`)를 선택하면 해당 폴더의 JPG를 촬영 시간순으로 지도에 연결합니다. 도로 경로와 AI 설명도 선택한 사진에 적용됩니다.
- 갤럭시 바로 열기: http://localhost:5173/?source=seongmin
- 지도에는 순서·날짜·시각을, 사진 목록에는 초 단위 시각·시간대·좌표를 표시합니다.
- 사진 또는 지도 표식을 누르면 해당 지점과 사진을 선택합니다.
- 시간·시간대·GPS가 없거나 손상된 사진은 제외 이유를 표시합니다.
- 사진을 추가한 뒤 새로고침하면 다시 읽습니다. 실제 도로 이동 경로를 복원하지는 않습니다.

사진과 좌표는 별도 파일로 생성하지 않습니다. 서버는 로컬 접속만 허용하며, `.env` 파일은 제공하지 않습니다. 지도용 JavaScript 키는 브라우저에서 사용하므로 개발자 도구에서 보일 수 있습니다.

검증: `npm test`. 지도 타일 로딩은 인터넷 연결과 유효한 카카오 키·도메인 설정이 필요합니다.
