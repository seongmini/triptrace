# 사진 경로 테스트

Node.js 22 이상에서 프로젝트 루트의 `.env`에 `KAKAO_MAP_JAVASCRIPT_KEY`를 설정하고, 카카오 JavaScript SDK 도메인에 `http://localhost:5173`을 등록합니다.

```sh
cd test
npm install
npm start
```

브라우저에서 http://localhost:5173 을 엽니다. 저장소 루트에서도 `node test/server.mjs`로 실행할 수 있습니다.

- `photo_sumin/`의 JPG를 읽어 촬영 시간순으로 지도에 연결합니다.
- 지도에는 순서·날짜·시각을, 사진 목록에는 초 단위 시각·시간대·좌표를 표시합니다.
- 사진 또는 지도 표식을 누르면 해당 지점과 사진을 선택합니다.
- 시간·시간대·GPS가 없거나 손상된 사진은 제외 이유를 표시합니다.
- 사진을 추가한 뒤 새로고침하면 다시 읽습니다. 실제 도로 이동 경로를 복원하지는 않습니다.

사진과 좌표는 별도 파일로 생성하지 않습니다. 서버는 로컬 접속만 허용하며, `.env` 파일은 제공하지 않습니다. 지도용 JavaScript 키는 브라우저에서 사용하므로 개발자 도구에서 보일 수 있습니다.

검증: `npm test`. 지도 타일 로딩은 인터넷 연결과 유효한 카카오 키·도메인 설정이 필요합니다.
